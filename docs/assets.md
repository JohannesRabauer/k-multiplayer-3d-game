# Third-party assets

The game uses selected assets by [Kenney](https://kenney.nl/). Each source
archive includes a `License.txt` granting the assets under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The original
license files are stored beside the imported models.

| Pack                  | Version | Project use                              | Source                                       | Modifications                                      |
| --------------------- | ------- | ---------------------------------------- | -------------------------------------------- | -------------------------------------------------- |
| Blocky Characters     | 2.0     | Player and enemy character models        | https://kenney.nl/assets/blocky-characters   | Renamed selected GLB files; transformed at runtime |
| City Kit (Commercial) | 2.1     | Buildings and plaza props                | https://kenney.nl/assets/city-kit-commercial | Renamed selected GLB files; transformed at runtime |
| Car Kit               | 3.1     | Drivable cars, crates, and traffic cones | https://kenney.nl/assets/car-kit             | Renamed selected GLB files; transformed at runtime |

Attribution is not required by CC0, but the game credits Kenney to make the
asset provenance explicit.
