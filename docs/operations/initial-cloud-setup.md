## Initial Cloud Run deployment

The first service revision must use explicit conservative limits:

```text
Ingress: all (public game endpoint)
Authentication: application-level Firebase token
Minimum instances: 0
Maximum instances: 1
CPU: TBD after container measurement
Memory: TBD after container measurement
Concurrency: TBD after four-player load test
Request timeout: long enough for WebSocket sessions, within Cloud Run limits
Runtime service account: TBD
Allowed browser origin: GitHub Pages production URL only
```

Do not increase maximum instances until room ownership is designed. Cloud Run
session affinity is not a correctness guarantee for game-room routing.
